# 文件上传与附件生命周期

涉及上传、附件或上传后的解析任务时阅读。界面状态以服务端确认的附件状态为依据。

## 界面与接口约定

| 阶段 | 界面行为与接口依据 |
|---|---|
| 选择文件 | 展示名称、大小和可用的本地预览，提前提示类型或大小限制。 |
| 上传中 | 按真实传输量显示进度，可按现有能力取消。 |
| 服务端处理中 | 上传字节完成后，按返回状态显示解析、转码或安全检查，直到附件可用。 |
| 可使用 | 使用服务端确认的附件 ID，提交消息时约定附件必须就绪还是由服务端排队等待。 |
| 失败或取消 | 保留适用的文件信息，说明失败发生在哪个阶段，提供对应的重试或重新选择入口。 |

接口按需返回上传操作 ID、附件 ID、处理状态、可理解的错误和允许的后续动作。状态名沿用项目契约。

## 重试与访问边界

- 上传超时先查询同一操作的状态。原文件重试复用可识别的上传会话，避免重复创建附件。处理失败可重试处理时，保留已上传文件。
- 断点续传依赖服务端协议。已支持时记录会话、有效期和偏移或已确认分片，恢复前向服务端核对。采用 tus 时，按其偏移检查与冲突响应处理。
- 取消传输与取消后续处理分别约定。等待服务端确认最终状态，临时文件清理由服务端策略负责。
- 前端类型和大小预检改善反馈。实际类型、大小、用户归属和读取权限由服务端校验。预览与下载链接遵循对应权限和有效期，敏感凭据不放入公开地址。

## 验收

检查超大或不支持的文件、传输中断、上传完成但解析失败、重试、取消与完成竞速，以及访问链接过期。确认附件就绪前的状态可辨认，重复操作不会多创建一份业务附件。

参考 [OWASP 文件上传](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) 和 [tus 断点续传协议](https://tus.io/protocols/resumable-upload)。

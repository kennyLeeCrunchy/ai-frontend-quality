# 作者新视频 / 外部 Skill：使用边界与技术核验

- 原始仓库：[Ludi-Herry/desktop-agent-ui](https://github.com/Ludi-Herry/desktop-agent-ui)；作者仓库 LICENSE 为 MIT，代码和说明仍以原仓库及其后续版本为准。
- 新视频 5 点：IME 选字不误发；流式阅读视口不被拽走；减少多层外框；内外圆角同心；分屏拖拽与收缩。额外提醒：长文件名后缀须保留。
- 本 Skill 的新增 examples 是根据需求独立编写的最小参考片段；**没有打包复制或自动执行作者仓库中的脚本**。若开发者需要 clip-audit，请去官方仓库查阅最新脚本并审查再运行。

## 值得吸收

1. 输入法多状态和浏览器兼容验证；增量生成中的阅读意图优先。
2. 滚动与分屏状态机的正常完成、主动取消、自动折叠等完整生命周期。
3. 内外裁切、阴影安全边距、可访问性焦点和缩放检查。
4. 工具执行过程、待授权、停止中/已停止必须与真实后端状态一致。
5. 已有设计系统先复用，不把视觉建议误写为必须换框架。

## 必须保留的批判性核验

- **500ms 的 post-composition Enter 拦截**只是作者给出的特定策略，不是跨 IME 万能阈值；可能吞掉用户真实的快速 Enter。应结合 isComposing、keyCode 229 兼容处理，设短时可调的一次性 fallback 并实测。
- **CSS Scroll-Driven Animations 可以减少 JavaScript 介入，但不代表真实 CPU 恒为 0 或所有情况下都在合成器运行**；需要浏览器支持检测与性能测量。
- **`box-shadow` 的 blur 并非严格像素可见边界**，靠 offset+blur+spread 做余量是一种保守近似。
- **clip-audit 脚本的 `cut===0` 不是最终视觉正确性证明**：可能漏掉 clip-path 形状、滚动边界、动态中间帧、真实 GPU/窗口裁切或产生误报。用截图、真实窗口和手工核对。
- **分屏 18%/82% 仅是示例吸附阈值**，窄窗口时可能与最小可用宽度矛盾；必须结合实际容器宽度以及单列/Drawer 降级。
- **隐藏滚动条**可能让用户误以为内容不可滚；无障碍优先，谨慎应用。
- **多窗口 Broker / Replica** 是有多窗口共享可写资源需求时的可选架构，不能套用到普通 Web 单标签页。

## 和本 Skill 的职责关系

作者偏桌面桌面壳/控件微交互；本 Skill 保留独立的组件需求确认、Web 响应式、Reload vs Remount vs Refetch 诊断、局部 Loading、跨对话 TaskManager、SSE 断线恢复，以及测试示例。二者在理念上互补：**复用核心原则，不将多份入口 Skill 的指令机械叠加**。

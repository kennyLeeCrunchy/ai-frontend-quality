# 登录会话与权限变化

用于会话过期、账号切换和资源访问权限变化。设备麦克风等权限的首次请求见 [专门场景](specialized-page-patterns.md#首次使用与权限请求)。

## 过期与重新登录

- 区分身份认证失效和当前身份无权执行。项目以 401、403 或业务码表达时，先确认契约，避免对权限拒绝反复刷新凭据或弹出登录。
- 重新登录期间，按产品和隐私策略暂存当前操作上下文与草稿。敏感草稿的持久化需有明确策略和清理方式。
- 已有刷新凭据机制时，协调并发失败请求，避免多个刷新和多个登录弹窗。只在确认身份有效、操作仍适用且可安全重放时恢复请求。
- 对会产生副作用的提交，先查询原操作结果或使用已有幂等机制，再决定重试。

## 权限撤销与账号切换

- 用户失去某个资源的权限时，收敛该区域的操作并提供可用的返回或申请权限入口，依据服务端错误处理。
- 切换账号或工作区时，停止旧上下文的订阅与请求，隔离或清理其缓存和预览。将延迟响应与用户、租户或会话标识匹配后再写入状态。
- 重新登录后先确认用户身份与资源权限，草稿和待执行操作仅恢复到其所属上下文。

## 实际访问控制

前端的隐藏或禁用状态是交互提示。每次读取、下载和修改的授权由服务端执行，包括通过资源 ID 发起的直接请求。会话失效时按项目统一的认证机制处理。

## 验收

验证多个请求同时过期、重新登录失败或取消、切换到另一账号后旧响应到达、任务运行中权限撤销，以及下载权限失效。检查缓存、草稿和重试均归正确用户。

参考 [OWASP 授权指南](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。
